# home-robo

A four-wheel robot on a Raspberry Pi 5 that drives, obeys, follows, listens and remembers. Built for fun in Gurgaon, one stage at a time.

- [Plan and stages](docs/plan.md)
- [Order list with Indian links](docs/order-list.md)
- [Stage 0: headless Pi setup, assembly and Freenove's tests](docs/pi-setup.md)
- [Stage 1 guide: line following and obstacle stop](docs/stage1-guide.md)
- [Code](robot/)

Claude is the engineer; the owner wires, flashes, tests and sends photos and logs. `CLAUDE.md` carries the context for every session.

Start every session from inside this folder so that context loads:

```
cd ~/home-robo && claude
```

When the parts arrive, the message that moves things forward is "kit arrived, starting stage 0" with a photo of the unboxed parts.
